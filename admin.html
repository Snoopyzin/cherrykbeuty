Conectar ao site

Para publicar, o painel precisa de uma chave de acesso do GitHub. Ela só precisa ser criada uma vez e fica guardada neste aparelho.

Como criar a chave (passo a passo)
  1. Entre no GitHub com a conta dona do site e abra github.com/settings/personal-access-tokens/new.
  2. Em Token name, escreva Painel Cherry. Em Expiration, escolha o maior prazo (1 ano).
  3. Em Repository access, marque Only select repositories e escolha cherrykbeuty.
  4. Em Permissions → Repository permissions, procure Contents e mude para Read and write.
  5. Clique em Generate token, copie o código que começa com github_pat_ e cole abaixo.
